# Rust Todo List

This is a simple command line todo list app written in Rust as an exercise with specific goals in mind:

## Available commands

```
Available commands:

    - add [TASK]
        Ads new task/s
        Example:  add Build a tree

    - list
        Lists all tasks
        Example:  list

    - toggle [ID]
        Toggles the status of a task (Done/Pending)
        Example:  toggle 2

    - rm [ID]
        Removes a task
        Example:  rm 4

    - reset
        Deletes all tasks
        Example: reset

```

## Development commands:

```sh
# to run once
cargo run 

```
